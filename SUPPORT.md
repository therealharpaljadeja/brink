# Support

Brink is experimental, unaudited, community-maintained, best-effort monitoring
software. Use it with caution and do not rely on it as your only liquidation
warning.

## Questions

Use GitHub Discussions when enabled for setup help, architecture questions, and
ideas that are not yet scoped enough for an issue. Include your macOS and Xcode
versions, but never include private keys, seed phrases, authentication headers,
or private RPC URLs.

## Bugs

Use the GitHub bug-report form for reproducible, non-security problems. Include
the smallest reproduction and sanitized logs or screenshots. Public wallet
addresses can reveal financial activity; redact them unless they are essential
and belong to you.

## Security

Do not request vulnerability help publicly. Follow [SECURITY.md](SECURITY.md)
and use GitHub private vulnerability reporting.

## Financial safety

Maintainers cannot prevent liquidation, recover funds, reverse transactions, or
guarantee that an alert arrives. Always verify a position directly through Aave
and the relevant blockchain explorer before acting.
